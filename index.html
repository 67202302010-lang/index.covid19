ปัจจัยเสี่ยงและสถานที่สัมผัสโรค (Risk Environments)

สรุปผลการวิเคราะห์ทางระบาดวิทยาเชิงพื้นที่ & วิธีการติดตั้งบน GitHub Pages

สรุปเชิงระบาดวิทยา (Epidemiological Summary):

  • การกระจายเชิงพื้นที่: พื้นที่ที่มีความหนาแน่นสูงที่สุด ได้แก่ กรุงเทพมหานครและปริมณฑล (สมุทรปราการ นนทบุรี นครปฐม) รวมถึงเมืองศูนย์กลางภูมิภาค เช่น ชลบุรี ขอนแก่น และบุรีรัมย์
  • ปัจจัยเสี่ยงหลัก: การสัมผัสใกล้ชิดกับผู้ป่วยยืนยันก่อนหน้า และการสัมผัสเชื้อในพื้นที่ชุมชน/ตลาด
  • กลุ่มเสี่ยงสูง: ผู้สูงอายุ (60 ปีขึ้นไป) มีสัดส่วนการสูญเสียและอาการรุนแรงสูงที่สุด แม้จำนวนผู้ติดเชื้อส่วนใหญ่จะอยู่ในช่วงวัยทำงาน (31-45 ปี)

ขั้นตอนการนำไฟล์ขึ้น GitHub Pages (Deployment):

  1. สร้าง Repository ใหม่บน GitHub เช่น covid19-thailand-dashboard
  2. บันทึกซอร์สโค้ดนี้เป็นไฟล์ชื่อ index.html แล้ว Upload ขึ้นไปที่ Repository
  3. ไปที่เมนู Settings > Pages
  4. ในส่วน Build and deployment ให้เลือก Source เป็น Deploy from a branch และเลือก Branch main / root
  5. กด Save ระบบจะสร้าง URL แดชบอร์ดสำหรับใช้งานสาธารณะทันที
